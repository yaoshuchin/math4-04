# 除法探索樂園 - 國小四年級數學互動教室 (math4-04)

專為國小四年級數學「除法」單元設計的互動教學網站。

## 功能特色

1. **分蘋果遊戲**：生活化具象平分與分裝操作，直觀掌握商與餘數的意涵。
2. **錢幣分裝模擬**：百元鈔與十元硬幣退位換錢動態操作，理解退位與位值觀念。
3. **直式解剖與位值對齊**：逐步動態引導除法直式的商、乘、減、帶下四步驟。
4. **估商調商實驗室**：二位數除法的調商練習，動態判斷估太大或估太小。
5. **對決闖關遊戲**：雙人/電腦即時對抗答題，活化計算練習。
6. **10 題互動評量**：包含即時音效反饋、成績結算與答題解析。
7. **懸浮草稿計算紙**：畫面上隨點隨開的草稿板，支援方格輔助線與一鍵清除。
